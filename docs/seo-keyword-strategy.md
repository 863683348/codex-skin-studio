## 三、落地操作（按优先级排序）

### ✅ 立即做（本周）

1. **站内 SEO 基础**
   - 确保每个页面的 `<title>` 和 `<meta description>` 自然含 Tier 1 关键词
   - `/zh` 页面标题：`Codex Skin Studio - Codex 换肤工具 | 免费 Codex 主题下载`
   - `/zh/pricing` 标题：`定价 - Codex Skin Studio | Codex 换肤主题套餐`
   - 英文 `/en` 对标

2. **JSON-LD 结构化数据已就位**（昨天⑩已做）
   - Organization + SoftwareApplication + AggregateOffer

3. **Sitemap 已就位**（MVP 阶段完成）

### 🔜 下一步做（1–2 周内）

4. **建 Blog / 文章区**
   - 第一篇：`Codex Dream Skin 是什么？Codex 换肤完全指南`（截 Flow，说清原理、安全、对比）
   - 第二篇：`2026 年最好看的 Codex 主题盘点`（对照搜索热词，用你的 Gallery 做 SEO landing）
   - 第三篇：`Codex 自定义主题教程——从零做一套自己的皮肤`（长尾 SEO + 用户粘性）
   - 每篇文章 hreflang 中英文双版

5. **外链 / 社交信号**
   - 参考原项目的爆火模式：在 **X/Twitter** 发截图 → 自然上热搜
   - 在 **开源中国 / 掘金 / 知乎** 发技术文（「如何给 Codex 换肤」类）
   - YouTube 短视频：Codex 换肤效果展示

### 🏆 品牌差异化（中长期）

6. **与 Codex Dream Skin 区隔**
   - 关键词策略：强调「Studio」的品牌感，引导用户搜索 "Codex Skin Studio" 而非 "Dream Skin"
   - 功能差异化点：Firebase 登录保存主题偏好、Pro/Team 套餐（Dream Skin 没有）
   - 社区策略：开放用户上传主题 → 积累 UGC 内容 → 自然 SEO 流量
